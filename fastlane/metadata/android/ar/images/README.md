# أصولُ صفحة المتجر (تُجهَّز يدويّاً)

هذه الأصول تُلتقط من جهازٍ حقيقيٍّ ولا تُركَّب (مراجعةُ بلاي ترفض اللقطة التي لا تمثّل التطبيق):

- `icon.png` — 512×512 · PNG 32‑بت · < 1024 ك.ب (تُولَّد من أيقونة التطبيق بلوحته).
- `featureGraphic.png` — 1024×500 · PNG 24‑بت أو JPEG · بلا شفافيّة.
- `phoneScreenshots/` — لقطتان على الأقلّ للنشر، و4 بدقّة 1080+ للترشيح للعرض (9:16 رأسيّ).

البنية نفسها (`fastlane/metadata/android/ar/`) تخدم غوغل بلاي وF‑Droid معاً.
